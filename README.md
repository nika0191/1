## ✨ Обновление

Ozon недавно изменил методику расчёта среднего рейтинга товара, и таблица была полностью переработана под новую логику. Изменения в самой таблице в основном косметические.

## 🧩 Как пользоваться

1. Файл → Создать копию
2. Вставьте отзывы на лист «1. Отзывы»
3. На листе «2. Настройки» выставьте, какой артикул в какой склейке находится
4. Готово

## 📊 Сводная таблица

На листе «Сводная таблица» отображается:

- Средневзвешенная оценка с учётом веса каждой оценки
- Сколько пятёрок нужно до вашей желаемой оценки

Также можно посмотреть несредневзвешенную среднюю оценку по дням и месяцам:

- по артикулам
- по склейкам

Таблица бесплатная.

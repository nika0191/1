# HeroUI React Components

A Vite + React + TypeScript app showcasing [HeroUI](https://heroui.com) v3 React components, built on Tailwind CSS v4 and React Aria Components.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL. The home page links to `/components`, a categorized tour of buttons, forms, controls & feedback, data display, navigation, and overlay components.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — lint and auto-fix

## Stack

- [Vite](https://vitejs.dev/)
- [React 19](https://react.dev/)
- [HeroUI](https://heroui.com) (`@heroui/react`, `@heroui/styles`)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [react-router-dom](https://reactrouter.com/)
- [lucide-react](https://lucide.dev/) for icons

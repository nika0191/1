# Pixabay Image Gallery - React & Tailwind CSS

Simple gallery with images from the pixabay API. Tailwind CSS is built into the workflow with postcss and autoprefixer.

## Usage
Copy `.env.example` to `.env` and add your Pixabay API key - https://pixabay.com/api/docs/

```
# Install dependencies
npm install

# Watch CSS & run server on :3000
npm start

# Build CSS and assets
npm run build
```

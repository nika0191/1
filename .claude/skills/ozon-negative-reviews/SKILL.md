# Обработка негативных отзывов на Ozon Seller

## Требования к окружению

Этот скилл нельзя выполнить без:
- **Реального Chrome пользователя** (не изолированный/headless браузер) — кнопка «Написать в чат» в Ozon Seller блокируется как попап в изолированных браузерах.
- Действующей авторизованной сессии в **Ozon Seller** (business.ozon.ru или seller.ozon.ru — в зависимости от кабинета).
- Доступа на **чтение и запись** к Google-таблице «Работа с негативными отзывами».

Если хотя бы одно из условий не выполняется — остановиться и сообщить об этом, а не имитировать выполнение.

## Шаг 0. Разведка магазина

1. В правом верхнем углу кабинета Ozon Seller — выпадающий список с названием компании. Переключиться на нужный магазин.
2. Все дальнейшие действия (Отзывы, Вопросы, Товары) выполняются **только в рамках текущего выбранного магазина** — разделы не общие по всем компаниям сразу. Если магазинов несколько, каждый магазин обрабатывается отдельным проходом по этому скиллу, начиная заново с шага 0.
3. Название текущего магазина понадобится на шаге 5 — это имя листа в Google-таблице (Supra, FourCleaning, GetPacket, Cleaning, GoAction, Get, Экотех, Jara, Gaz, Nekilvex, To the Moon и т.д.).

## Шаг 1. Актуальный список товаров с остатком >100 шт

⚠️ Остатки меняются постоянно — **этот шаг повторять перед каждой новой партией отзывов**, не использовать список с прошлого захода.

1. Перейти в Товары → Список товаров.
2. Прокрутить таблицу вправо — колонки «Склад Ozon» и «Мои склады» видны не сразу.
3. Для каждого товара посчитать сумму (Склад Ozon + Мои склады).
4. Составить (мысленно или во временном списке) перечень артикулов, где сумма > 100 шт. Только эти артикулы участвуют в обработке отзывов ниже.

## Шаг 2. Открыть отфильтрованный список отзывов

1. Товары → Отзывы.
2. Открыть Фильтры и выставить:
   - Оценка: 1, 2, 3
   - Статус получения: Получен
3. ❗ Не путать со счётчиком «Все» (например, «11214») — это ВСЕ отзывы без фильтра. Работать нужно во вкладке/срезе с применёнными фильтрами.

## Шаг 3. Критерий отбора конкретного отзыва в работу

Брать в работу отзыв только если оба условия верны:
- Оценка 1, 2 или 3, статус получения «Получен» (уже обеспечено фильтром на шаге 2).
- Артикул товара из отзыва входит в список товаров с остатком >100 шт, составленный на шаге 1.

Если товара нет в списке с остатком >100 — отзыв пропускается, к нему не переходить.

## Шаг 4. Обработка одного отзыва — порядок действий

Строго в этом порядке, для каждого отобранного отзыва:

1. **Сразу занести в Google-таблицу** (см. раздел «Google-таблица» ниже) со статусом «В работе» — до того, как отвечать под отзывом или писать в чат.
2. **Публичный ответ под отзывом**: отработать негатив по существу, не писать «напишите нам в чат» (мы сами пишем первыми) — например: «Приносим извинения за ситуацию, мы уже написали вам в чат — пожалуйста, ответьте там, чтобы мы могли быстрее решить вопрос».
3. Открыть чат с покупателем кнопкой «Написать в чат» на отзыве.
4. **Сообщение 1** — одним сообщением целиком (см. правило по переносам строк ниже): извинение + предложение решения — компенсация 15–35% (стартовать обычно с 15–20%) либо полный возврат через площадку.
5. **Сообщение 2** — отдельным сообщением: просьба удалить отзыв + «мы на связи, обязательно решим вопрос в вашу пользу», с уместными смайликами/сердечками, чтобы расположить человека к диалогу.
6. Обновить строку в таблице (Комментарий, Ссылка на чат).

### Правило ввода текста в чат Ozon

В поле сообщения чата Enter = отправка. Чтобы сообщение ушло одним куском с абзацами:
- Не печатать текст построчно с обычным `\n` между строками — построчный ввод с Enter отправит несколько отдельных сообщений.
- Вставлять весь текст сообщения сразу целиком (например, через буфер обмена / paste), либо использовать Shift+Enter для переноса строки внутри одного сообщения, если это поддерживается интерфейсом.
- Сообщение 1 и Сообщение 2 — это два разных вызова отправки, не один.

### Шаблон Сообщения 1 (адаптировать под ситуацию)

```
Здравствуйте! Приносим извинения за то, что товар вас расстроил — это точно не тот опыт, который мы хотим для наших покупателей.

Готовы решить вопрос в вашу пользу: можем предложить компенсацию в размере 15-20% от стоимости заказа, либо оформить полный возврат через площадку — как вам будет удобнее.

Напишите, пожалуйста, какой вариант вам подходит, и мы сразу всё оформим.
```

### Шаблон Сообщения 2

```
И ещё маленькая просьба 🙏 Если вопрос для вас решён (или как только решится) — не могли бы вы удалить отзыв? Нам это очень поможет 💛

Мы на связи и обязательно решим вопрос в вашу пользу, спасибо за терпение! 😊
```

## Шаг 5. Google-таблица «Работа с негативными отзывами»

- Лист = название текущего магазина (см. шаг 0).
- Каждый отобранный отзыв — отдельная строка со следующими колонками:

| Колонка | Содержимое |
|---|---|
| A. Дата | дата отзыва |
| B. Взял в работу | имя из дропдауна — Вероника |
| C. Артикул товара | артикул из карточки отзыва |
| D. Количество звёзд | оценка |
| E. Номер отправления | номер заказа |
| F. Отзыв | текст отзыва целиком |
| G. Статус | «В работе» (пока отзыв не удалён/статус не обновлён) |
| H. Решение | дропдаун (Возврат через площадку / Замена / Частичная компенсация и т.д.) — заполнять **только когда решение подтверждено покупателем**, не на этапе предложения |
| I. Комментарий | краткая суть, например «20% предложено» |
| J. Ссылка на чат | URL диалога с этим покупателем |

### Технические ловушки при работе с Google Таблицами

- Строки с длинным текстом отзыва визуально «растягиваются» — клик по координатам может промахнуться на другую ячейку. Надёжнее: кликнуть на заведомо известную ячейку и двигаться стрелками, каждый раз проверяя реальный адрес в Name Box перед вводом.
- При вводе артикула в колонку C иногда обрезаются первые ~15 символов — вводить в два захода и проверять по строке формул перед подтверждением.

## Шаг 6. Повторные проверки (пинг неответивших)

Для отзывов со статусом «В работе», где покупатель ранее не ответил:
1. Перейти по ссылке на чат (колонка J).
2. Посмотреть переписку, проверить, удалён ли отзыв.
3. Если отзыв удалён/вопрос решён — обновить статус и решение в таблице.
4. Если нет — написать покупателю ещё раз: спросить, решился ли вопрос, повторить вежливую просьбу удалить отзыв.

## Шаг 7. Возвраты/отмены (FBO)

Отдельно от отзывов: FBO → заявки на возврат/отмену. Здесь тоже сначала предлагать решение (желательно компенсацию), и только после этого принимать/отклонять возврат.

## Шаг 8. Чаты с покупателями (общие, не по отзывам)

Отдельный значок сообщений — туда пишут с вопросами по товару/возврату вне карточки отзыва. Разбирать по контексту, без жёсткого сценария.

## Шаг 9. Итог недели

В конце каждой недели — закрыть таблицы с расчётами (свести статусы/решения по всем обработанным отзывам за неделю).

## Итоговый чек-лист перед закрытием партии отзывов

- [ ] Магазин выбран верно (шаг 0)
- [ ] Список товаров с остатком >100 обновлён заново, а не взят из прошлого раза (шаг 1)
- [ ] Фильтр отзывов: Оценка 1-3 + Статус «Получен» (не вкладка «Все»)
- [ ] Каждый отзыв внесён в таблицу до ответа/переписки
- [ ] Публичный ответ не отправляет покупателя «в чат» без объяснения, что чат уже написан нами
- [ ] Сообщение 1 и Сообщение 2 отправлены как два отдельных сообщения, каждое — единым куском текста
- [ ] Колонка H («Решение») заполнена только по подтверждённым решениям
- [ ] Ссылка на чат сохранена в таблице

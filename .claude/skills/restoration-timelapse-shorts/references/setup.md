# Подключение сервисов

## Что уже есть у пользователя
| Сервис | Для чего в пайплайне | Как работает с Claude |
|---|---|---|
| **Google Flow** (подписка Google AI Pro/Ultra) | Главный генератор видео: Veo 3.x, *Frames to Video* (первый+последний кадр), нативный звук, 9:16 | **Нет публичного API у Flow.** Claude готовит кадры и промпты → ты загружаешь в Flow → скачиваешь клипы в `clips/` → Claude собирает. |
| **Grok** (SuperGrok / X Premium) | Кадры и правки (Grok Imagine), быстрые image-to-video вставки, мозговой штурм идей | Подписка в приложении **не даёт API-кредитов**. Работа руками в grok.com / приложении. |

## Уже подключено к Claude в этой среде (можно пользоваться сразу)
| Коннектор | Польза |
|---|---|
| **BFL / FLUX** (`mcp__Bfl_ai__*`) | Цепочка стадий через FLUX Kontext прямо из Claude + видео по ключевым кадрам. Лучший способ автоматизировать шаг 3 без ручной работы. Платится кредитами BFL (`get_credits`). |
| **nexlev**, **vidIQ** | Разведка ниши, аутлайеры, ключевые слова, аналитика своего канала (после авторизации YouTube). vidIQ умеет загружать видео на YouTube (`vidiq_video_upload`) и обновлять метаданные. |
| **videogen** | Музыка и звуковые эффекты (`generate_music`, `generate_sound_effect`), апскейл видео. |
| **Google Drive** | Обмен файлами: клади клипы из Flow в папку Drive — Claude скачает их для сборки. |
| **Notion** | Контент-план/трекер эпизодов (по желанию). |

## Рекомендую подключить
1. **Авторизовать свой YouTube-канал в vidIQ** (`vidiq_authorize_with_youtube`) — тогда Claude видит
   твою аналитику (удержание, свайпы) и может загружать ролики. Это закрывает «автоматизацию публикации».
2. **Gemini API ключ** (aistudio.google.com) — *только если* нужна полностью автоматическая генерация
   видео без ручной работы во Flow. Veo через API оплачивается отдельно от подписки (за секунду видео),
   поэтому начинай с Flow вручную, а API включай, когда формат доказал себя.
3. **xAI API ключ** (console.x.ai) — по той же логике для Grok: отдельные платные кредиты. Не обязателен.
4. **Музыка**: YouTube Audio Library (бесплатно, безопасно для монетизации) или генерация через videogen.
   Чужие треки из TikTok не используй — Content ID снимет монетизацию.
5. **ffmpeg** на твоём компьютере (для `assemble.sh`): macOS `brew install ffmpeg`, Windows `winget install ffmpeg`.

## Рабочий цикл «полуавтомат» (рекомендуемый старт)
1. Claude: идея → `new_episode.py` → промпты, якорный кадр и стадии через FLUX (или ты делаешь в Grok).
2. Ты: Flow → Frames to Video по каждой паре кадров → скачать в `episodes/<slug>/clips/` (или в Drive).
3. Claude: `assemble.sh` → проверка кадров → метаданные → загрузка через vidIQ (после твоего «ок»).

На один ролик уходит ~20–30 минут ручного времени; пачка из 5 роликов — вечер.

## Полный автомат (когда будут API-ключи)
FLUX (стадии) → Veo через Gemini API (переходы) → `assemble.sh` → vidIQ upload.
Запуск по расписанию — Routine в Claude Code («каждый день в 10:00: следующий эпизод из плана»).
Всё равно оставляй себе финальный просмотр перед публикацией.

## Правила YouTube, которые нельзя пропускать
- **Раскрытие AI**: при загрузке отметить «Altered or synthetic content» (реалистичный AI-контент).
- **Inauthentic content** (бывш. «повторяющийся контент»): массовые одинаковые ролики → отказ в монетизации.
  Меняй объекты, твисты, звук; добавляй историю объекта в описание.
- Реальные места показывай как **концепт**, не утверждай, что объект реально восстановлен.

# Restoration Timelapse Shorts

Скилл ведёт один ролик (или пачку) от идеи до готового MP4 1080×1920 и пакета метаданных.
Главный принцип ниши: **смотрят не ремонт, а историю объекта**. Безымянная «Abandoned Villa Restoration»
в 2026 году собирает сотни просмотров; реальное место, неожиданное превращение или человек,
для которого строят, — миллионы. Подробности и цифры: `references/niche-analysis.md`.

## Файлы скилла

| Файл | Когда читать |
|---|---|
| `references/niche-analysis.md` | Выбор темы, идеи, «чего нет у конкурентов», заголовки |
| `references/prompts.md` | Генерация кадров и видео: шаблоны промптов для Grok, Flow/Veo, FLUX |
| `references/setup.md` | Подключение сервисов, что куда входит, что докупить |
| `scripts/new_episode.py` | Создаёт папку эпизода с планом и готовыми промптами |
| `scripts/assemble.sh` | Склейка клипов в Shorts 9:16, скорость, музыка, хук-текст, проверка петли |

## Пайплайн

### 1. Идея (5 мин)
Прочитай `references/niche-analysis.md`, раздел «Формула темы». Тема обязана пройти фильтр:
- **Конкретный объект** (не «старый дом», а «водонапорная башня 1912 года в Выборге», «вагон-ресторан СВ 1970-х»),
- **Крючок-превращение** (восстановить как было / переделать во что-то неожиданное / для кого-то),
- **Одна деталь-интрига в первом кадре** (дерево растёт сквозь крышу, паровоз в лесу по колёса в земле).

Если пользователь просит идеи — выдай 10 штук по формуле и отметь 3 лучших. Для проверки спроса
можно вызвать `mcp__vidIQ__vidiq_keyword_research` и `mcp__nexlev__youtube_search` (type=shorts, sort_by=views).

### 2. Эпизод
```bash
python3 .claude/skills/restoration-timelapse-shorts/scripts/new_episode.py \
  --slug water-tower-vyborg --object "1912 brick water tower on a hill" \
  --place "Vyborg, Russia" --twist "restored as it was" --stages 6
```
Создаётся `episodes/<slug>/` с `plan.md` (стадии, промпты, чек-лист, метаданные) и папками
`frames/`, `clips/`, `audio/`, `out/`.

### 3. Шот-лист действий (ГЛАВНОЕ)
**Урок первого эпизода:** один неподвижный кадр, в котором стадии «перетекают» друг в друга, даёт
морфинг, а не ремонт. Зритель не видит ни рук, ни инструментов, ни работы, и ролик не цепляет.
У вирусных каналов (Bau Rausch, Structural.Aesthetics) ролик состоит из **8–12 коротких шотов действия**
по 2–3 с, снятых с разных ракурсов:
- **Общий план «до»** (хук) → **крупные планы работы** → **общий план «после»** с того же ракурса, что и «до».
- Каждый крупный план — одно понятное действие: ломом срывают гнилые доски, бензопила режет бревно,
  топор выбирает паз, кельма кладёт кирпич, кисть проходит по резьбе. Это и есть «satisfying».
- Звук каждого действия (хруст, пила, стук) важнее музыки.
- Эмоция в конце: человек, для которого восстанавливали, входит в дом (со спины).
- Одинаковыми должны быть **объект и персонажи** (в Flow — через *Ingredients*: загрузи кадр объекта
  и героя), а не ракурс.
Шаблоны шотов: `references/prompts.md` → «Шот-лист действий».

### 4. Генерация шотов
- **Google Flow (Veo)** — основной инструмент: text/ingredients-to-video, 9:16, 8 с на шот, звук нативный.
  Хорошо справляется с руками, инструментами, физикой (щепки, искры, пыль).
- **Grok Imagine** — быстрые дубли и запасные варианты шотов.
- Статичную цепочку стадий (`references/prompts.md` → «Цепочка стадий») используй **только** для
  общих планов «до/после» с одного ракурса, а не как основу ролика.
- Каждый шот **проверяй глазами до сборки**: руки, инструменты, объект не поменялся.
  Если результат не видно (сеть/доступ), не выдавай его как готовый: попроси пользователя посмотреть.
Сохраняй клипы как `clips/01.mp4`, `clips/02.mp4`… по порядку; `assemble.sh` сам не режет —
обрезай шоты до лучших 2–3 с в Flow/CapCut или скажи Claude, какие секунды оставить.

### 5. Сборка
```bash
bash .claude/skills/restoration-timelapse-shorts/scripts/assemble.sh episodes/<slug> \
  --speed 1.25 --music episodes/<slug>/audio/music.mp3 --hook "Этой башне 112 лет"
```
Результат: `out/final.mp4` (1080×1920, 30 fps, H.264, AAC, −14 LUFS), `out/first.jpg` и `out/last.jpg`
для проверки петли. Цель 20–35 с. Если в пути нужен свой ffmpeg — `FFMPEG=/путь/к/ffmpeg`.
Для тонкого монтажа (субтитры, переходы) можно подключить скилл `video-edit`.

### 6. Упаковка
Из `plan.md` бери блок метаданных и доработай:
- **Заголовок** ≤ 60 символов, с реальным местом/годом/цифрой. Пометка `[AI concept]` / `[ИИ-концепт]`
  в конце — снижает негатив в комментариях и не мешает охватам (у Bau Rausch 127M с такой пометкой).
- **Описание**: 2 строки истории объекта + вопрос в комментарии («Что восстановить следующим?»).
- 3–5 хэштегов: `#restoration #timelapse #beforeandafter` + тематический (`#abandoned`, `#train`).
- В YouTube Studio включи **«Altered or synthetic content»** — это требование YouTube для реалистичного AI.
- Опционально заголовок/описание на EN, DE, ES, PT — YouTube покажет их зрителям этих стран.

### 7. Проверка перед выдачей
- Первые 1,5 с — самая драматичная точка разрухи, без логотипов и заставок.
- Нет «плавающей» геометрии между стадиями, нет лишних пальцев у рабочих, нет водяных знаков.
- Последний кадр — финальный «вау», по возможности визуально стыкуется с первым (петля → досмотры).
- Громкость нормализована, музыка не глушит звуки стройки.

## Автоматизация и пакетный режим
- 5–10 эпизодов за раз: запускай `new_episode.py` для каждой темы, затем генерируй кадры пачкой.
- Повторяющийся контент-план — через Routines/`/loop` (например, «каждый понедельник: 7 идей + промпты»).
- Не публикуй одинаковые шаблонные ролики сериями без вариаций — YouTube отключает монетизацию
  за «inauthentic / mass-produced content». Меняй объект, историю, звук, структуру.
